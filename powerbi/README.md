# Power BI Board Pack

`Board_Pack.pbip` is a Power BI Project: the model, measures and pages are plain text files, generated by
`src/make_powerbi.py`, so every change is reviewable in Git.

## Open it
1. Open `Board_Pack.pbip` in Power BI Desktop (September 2026 release or later).
   On another computer, first run `python src/make_powerbi.py` (it writes your folder into the `ProjectFolder`
   parameter), or change the parameter in Power Query: Home → Manage Parameters.
2. The project stores no data. Click **Refresh now** on the yellow bar (or Home → Refresh).
   It reads the 25 monthly files in `data/exports/`.

## What's inside
| Part | Where |
|---|---|
| 4 pages, 63 visuals | `Board_Pack.Report/definition/pages/` |
| 13 tables, 10 relationships, 91 measures | `Board_Pack.SemanticModel/definition/` |
| Power Query (one file per query) | `power_query/` |
| Row-level security role "HRBP - Operations" | Modeling → View as → HRBP - Operations |
| Theme and page backgrounds | `theme.json`, `backgrounds/` |
| Screenshots | `screenshots/` |

Every chart title is a measure (`Title …`), so titles always describe the data on screen.

## Rebuild and check
```bash
python src/make_powerbi.py                                         # regenerate the project
powershell -ExecutionPolicy Bypass -File src/check_tmdl.ps1        # model parses in Power BI's own library
powershell -ExecutionPolicy Bypass -File src/check_powerbi_numbers.ps1   # with the report open: read every KPI
python src/compare_powerbi.py                                      # compare with the pandas reference (240/240)
```
Close the report in Power BI Desktop *without saving* before regenerating, or Desktop will write its older copy back.

## The refresh demo
Copy `data/demo_dropin/2026-10.csv` into `data/exports/`, click Refresh: every page moves to October 2026,
titles included. Move the file back afterwards.
